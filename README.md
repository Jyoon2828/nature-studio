# 자연 조각 생물 공방

초등학교 4학년 과학 「생물과 환경」 도입 활동용 웹앱입니다. 나뭇잎과 돌 이미지로 생물을 표현하고, 개인 작품을 모아 모둠 공동 작품을 만드는 활동입니다.

## 포함된 기능

- 6모둠, 학생 로그인 화면 없이 모둠 번호와 별명으로 참여
- AI로 제작한 실사 질감의 나뭇잎 8종, 돌 8종. 각 재료는 투명 PNG이며 인터넷 사진 검색 없이 사용
- 재료 클릭 추가 / PC에서 드래그 추가 / 작업판에서 손가락·마우스로 이동
- 크기 조절, 회전, 뒤집기, 맨 앞으로, 선택 삭제
- 그림 붓, 색상·굵기 변경, 지우개, 실행 취소·다시 실행
- 개인 작품 자동 임시 저장, 투명 PNG 다운로드
- 모둠 주제 공유, 개인 작품 제출·수정·삭제, 모둠 공동 작품 배치
- 모둠 배경 선택, 공동 작품 PNG 다운로드, 확대 발표
- 교사 화면의 6모둠 통합 전시회
- Firebase를 연결하면 다른 태블릿과 PC 사이 실시간 공유

## 먼저 알아두기

config.js에 nature-studio Firebase 프로젝트 설정을 반영했습니다. Authentication의 익명·Google 활성화, Firestore 생성, 교사 이메일을 넣은 규칙 게시, Vercel 도메인 허용을 완료해야 실제 수업 연결이 작동합니다. 앱 설정 값만 입력했다고 연결 확인이 완료된 것은 아닙니다.

학생에게 계정 생성·로그인 조작을 요구하지 않습니다. 내부적으로 Firebase의 익명 인증을 자동 사용하여 학생마다 자신의 제출 작품을 수정할 수 있도록 합니다. 교사는 Google로 로그인합니다.

이 파일은 GitHub·Vercel에 올릴 수 있는 완성 소스입니다. 사용자의 GitHub/Vercel 계정에는 아직 업로드하거나 배포하지 않았습니다.

## 1. Firebase 프로젝트 설정

1. https://console.firebase.google.com/ 에서 새 프로젝트를 만들거나 사용할 프로젝트를 선택합니다.
2. 프로젝트 설정 → 일반 → 웹 앱 추가(</>)에서 웹 앱을 등록합니다.
3. 제공하신 nature-studio 프로젝트의 firebaseConfig는 **config.js에 이미 반영되어 있습니다.** 이 단계는 완료했습니다. Analytics는 사용하지 않습니다.
4. Authentication → Sign-in method에서 **익명(Anonymous)**과 **Google**을 활성화합니다. Google 설정에는 지원 이메일을 지정합니다.
5. Firestore Database를 생성합니다. 운영 모드로 시작하고 원하는 지역을 선택합니다. 이 앱에는 Storage가 필요 없습니다.
6. **firestore.rules**에 교사 계정 `ete28@naver.com`을 반영했습니다. Google 로그인 시 이 이메일이 표시되는 Google 계정을 사용하세요. 여러 교사라면 `['teacher1@example.com', 'teacher2@example.com']`처럼 추가합니다.
7. Firestore Database → 규칙에 firestore.rules 전체를 붙여 넣고 게시합니다. 읽기·쓰기를 모두 허용하는 공개 규칙으로 바꾸지 마세요.
8. Vercel 배포 후 Authentication → Settings → Authorized domains에 배포 주소의 도메인(예: my-nature-app.vercel.app)을 추가합니다. 주소 앞 https://와 뒤 /는 넣지 않습니다. 새 프로젝트에서 localhost로 테스트한다면 localhost도 별도로 추가합니다.

config.js의 공개 웹 앱 설정은 클라이언트 연결용입니다. 서비스 계정 JSON이나 관리자 비밀키를 추가할 필요가 없습니다.

## 2. GitHub와 Vercel 배포

1. ZIP을 풀고 `nature-studio` 폴더 안의 파일들을 GitHub 새 저장소 최상위에 올립니다. index.html, app.js, assets 폴더가 최상위에 있어야 합니다.
2. Vercel → Add New → Project → 해당 GitHub 저장소 Import.
3. Framework Preset은 **Other**. Root Directory는 저장소 최상위로 설정합니다.
4. Build Command는 비워 둡니다. Output Directory는 `.`로 설정합니다. 설치할 패키지는 없습니다.
5. Deploy 후 Firebase 허용 도메인에 배포 도메인을 추가합니다.
6. config.js 또는 규칙을 변경했다면 GitHub 파일도 업데이트하세요. Firestore 규칙은 Firebase 콘솔에 별도로 게시해야 합니다.

## 3. 수업 열기

- 교사 주소: `https://배포주소/?role=teacher`
- 기본 학생 주소: `https://배포주소/`
- 교사가 복사하는 학생 주소: `https://배포주소/?room=수업이름`

1. 교사 화면에서 Google 로그인합니다.
2. 수업 이름을 입력합니다. 영문·숫자·하이픈·밑줄 3~40자를 사용합니다. 예: `class43-oct08`. 첫 수업은 기본값 `nature-class-1`도 가능합니다.
3. **수업 열기**를 누릅니다. 이름이 같으면 같은 수업 자료를 다시 불러옵니다. 새 수업은 새로운 이름으로 엽니다.
4. **학생 링크 복사**를 누르고 QR 또는 학급 게시판으로 공유합니다. 학생은 수업 코드를 따로 입력하지 않습니다.
5. 학생은 링크에 들어와 모둠 번호와 이름 또는 별명을 입력합니다.

여러 교사의 수업이 섞이지 않도록 교사마다 다른 수업 이름을 사용하세요. 학생 링크를 그대로 사용해야 같은 수업에 들어갑니다. 같은 기기의 인증 상태는 유지되므로 한 수업에서 처음 선택한 모둠을 바꾸는 것은 막혀 있습니다. 시작할 때 모둠을 정확히 선택하도록 안내해 주세요. 교사와 학생은 서로 다른 기기로 접속하는 것이 좋습니다.

## 4. 학생 활동 방법

1. 모둠 친구들과 한 가지 주제를 정합니다. 예: 바닷속 친구들, 숲속 생물, 학교 화단.
2. 모둠 주제를 입력하고 **주제 저장**을 누릅니다. 같은 모둠에게 공유됩니다.
3. 재료를 누르거나 PC에서 끌어 작업판에 추가합니다. 재료를 선택하여 이동·크기·방향을 바꿉니다.
4. **그리기**로 눈·다리·무늬 등을 더합니다. 이동하려면 **이동** 도구로 바꿉니다. 지우개는 지나간 위치의 재료와 그림을 함께 지웁니다. 재료 하나를 완전히 없애려면 이동 도구에서 선택 삭제를 사용합니다.
5. 생물 이름과 표현한 특징을 적고 **모둠에 작품 보내기**를 누릅니다.
6. **모둠 공동 작품**에서 친구들의 작품을 확인하고 끌어 배치합니다. 같은 작품을 동시에 옮기면 마지막으로 저장한 위치가 반영됩니다. 한 명씩 배치를 맡으면 좋습니다.
7. 수정할 때는 **내 작품**으로 돌아와 수정하고 다시 보냅니다. 개인당 제출 작품은 한 개이며, 다시 보내면 기존 작품이 바뀝니다.
8. 공동 작품의 배경을 정하고 발표합니다. PNG로 저장해 학급 게시판에 올릴 수 있습니다.

개인 작업판의 빈 여백은 투명하게 합쳐집니다. 공동 작품에 어울리도록 생물은 가운데에 충분히 크게 그려 주세요. 개인 작품에서 배경을 넓게 칠하면 다른 작품을 가릴 수 있으니 모둠 배경은 공동 작품 화면에서 선택하도록 안내하세요.

## 5. 교사 수업 흐름 예시 (도입 10~15분)

- 관찰: 돌과 나뭇잎의 모양을 보고 어떤 생물의 부분을 표현할 수 있을지 이야기합니다.
- 계획: 모둠 주제와 각자 만들 생물을 정합니다.
- 표현: 재료와 그림으로 생물의 특징을 나타냅니다.
- 협력: 개인 작품을 모아 하나의 모둠 장면으로 배치합니다.
- 발표: “어떤 생물을 표현했나요?”, “어떤 특징이 보이나요?”, “돌이나 떨어진 나뭇잎 자체도 살아 있는 생물일까요?”를 이야기합니다.

돌·떨어진 나뭇잎은 표현 재료이고 완성 그림도 실제 생물이 아닙니다. 표현한 생물의 모습에 주목하되, 살아 있는 생물과 재료를 구분하는 질문으로 다음 활동에 연결합니다.

## 저장과 운영

- 기기 내 임시 저장은 브라우저 데이터가 지워지면 사라집니다. 개인 작품은 제출 또는 PNG 저장으로 남기세요.
- 수집 작품과 주제·배치 데이터는 Firestore의 rooms/{수업이름} 아래에 저장됩니다.
- 교사 화면에서 모둠 카드를 누르면 확대 발표하고, 각 모둠 PNG 저장 버튼으로 공동 작품을 내려받습니다.
- 수업 이름을 새로 정하면 이전 수업과 분리됩니다. 오래된 수업 데이터 삭제는 Firebase 콘솔에서 해당 room 문서 및 하위 컬렉션을 함께 삭제하세요. 부모 문서만 삭제하면 하위 자료는 남습니다.
- 학생은 모둠의 주제·배치를 함께 바꿀 수 있고 자신의 제출 작품만 수정·삭제할 수 있습니다. 가입 학생은 교실 내 작품들을 읽을 수 있도록 구성되어 있으므로 민감한 개인정보는 입력하지 마세요.
- 인터넷 연결이 필요합니다. Firestore 연결이 실패하면 제출 성공이라고 표시하지 않으며 오류를 알립니다.

## 검증 범위

JavaScript 문법 검사, 체험 모드 데이터 저장·수정·삭제·탭 동기화 테스트, 이미지 파일·투명도 및 파일 연결 검사 완료. 이 실행 환경에서는 브라우저 화면 점검과 실제 Firebase 프로젝트의 권한·여러 기기 접속 검증을 수행하지 않았습니다. Firebase 설정 후 학생 기기 2대와 교사 PC로 같은 수업에서 제출·배치·발표를 확인한 뒤 수업에 사용하세요.

## 자연 이미지 제작 기록

내장 이미지 생성으로 실사 자연 재료 16종을 제작하고, 투명 PNG를 assets/material-01.png ~ material-16.png로 분리하여 포함했습니다. 생성 프롬프트는 ASSET_PROMPT.txt에 기록했습니다.

## 두 손가락 조작 업데이트

개인 작업판의 ‘이동’ 도구에서 나뭇잎·돌을 직접 조작할 수 있습니다.
- 한 손가락: 재료 선택과 이동
- 두 손가락 벌리기·오므리기: 확대·축소
- 두 손가락 비틀기: 회전
- 두 손가락 중심 이동: 재료 위치 이동
- 한 손가락을 떼면 남은 손가락으로 자연스럽게 이동을 이어갈 수 있습니다.

첫 손가락을 재료 위에 대고 두 번째 손가락을 작업판 안에 대세요. 이동·확대·회전을 한 동작으로 해도 실행 취소 한 번으로 되돌립니다. 그리기·지우개 도구에서는 추가 손가락으로 그림을 그리지 않습니다. 기존 크기·회전 버튼은 그대로 사용할 수 있습니다. 모둠 공동 장면에 제출된 전체 작품의 배치는 기존 한 손가락 이동 방식입니다.

GitHub의 app.js와 index.html을 이번 파일로 교체하면 됩니다. 기존 assets·Firebase 설정·Firestore 규칙은 그대로 사용합니다. 실제 갤럭시탭 터치 동작은 배포 후 확인하세요.

## 자연 재료 이미지 업데이트
돌 8종을 여백이 충분한 실사 이미지로 교체하여 가장자리 잘림과 옆 돌 조각이 섞이는 문제를 수정했습니다. 노란 자작나무 낙엽·주황 느티나무 낙엽 2종을 추가해 나뭇잎은 총 10종, 돌은 8종입니다. GitHub의 assets 폴더 전체, app.js, index.html을 교체하세요. 두 손가락 조작 기능은 유지합니다.
